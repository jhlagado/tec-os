## CPU address space

| Addresses | Contents |
| --- | --- |
| 0000h–07FFh at reset | Boot overlay: ROM C000h–C7FFh |
| 0000h–00FFh | CP/M page zero; 0040h–004Fh TEC-OS fixed state |
| 0100h–B805h | Classic TPA, 46854 bytes |
| B806h–BFFFh | BDOS entry jump and resident workspace in EXPAND 0 |
| 8000h–BFFFh | EXPAND 0 (classic workspace and TPA) or EXPAND 1 |
| C000h–FFFFh | TEC-OS ROM |

The word at 0006h is B806h on the starter card; cold boot sets it
for the volumes mounted, below their allocation vectors (four 8 MiB volumes
give B506h). The word at 0001h points into the RAM BIOS table at
BF00h.

## Page zero, 0040h–004Fh

CP/M leaves these bytes to the BIOS. TEC-OS keeps here the state that must
stay in view whatever EXPAND shows.

| Address | Name | Contents |
| --- | --- | --- |
| 0040h | `LATCHV` | shadow copy of the system latch |
| 0041h | `MAINS` | MAIN regions fitted, 1 or 2 (ABIMAIN points here) |
| 0042h | `RXFULL` | console byte waiting in RXCHAR |
| 0043h | `RXCHAR` | and the byte itself |
| 0044h | `EXPANDS` | EXPAND regions fitted: always 2, MEMINIT stops on fewer |
| 0045h | `CONDEV` | console devices present (CD* bits) |
| 0046h | `VROW` | video terminal cursor row |
| 0047h | `VCOL` | and column |
| 0048h | `VWID` | video columns |
| 0049h | `VHGT` | video rows |
| 004Ah | `ESCST` | escape parser state |
| 004Bh | `ESCP1` | first numeric parameter |
| 004Ch | `ESCP2` | second numeric parameter |
| 004Dh | `KBLAST` | matrix key held at the last poll, FFh none |
| 004Eh | `VATTR` | 80h while reverse video is on |
| 004Fh | `VCURV` | 1 while the cursor cell is inverted |

## EXPAND 1

Cold boot clears it. Programs reach none of it: `XMOVE` and `MOVE` refuse
every byte of bank 1.

| Addresses | Bytes | Contents |
| --- | ---: | --- |
| 8000h–BBFFh | 15360 | the block cache's 30 lines, 512 bytes each |
| BC00h–BC77h | 120 | each line's card block, 4 bytes, FFFFFFFFh while empty |
| BC80h–BC9Dh | 30 | each line's dirty byte, nonzero while the card lacks its changes |
| BD00h–BDFFh | 256 | command history |
| BE00h–BEFFh | 256 | the CCP's levels |
| BF00h–BFFFh | 256 | reserved |
