# Thorium manuals

Thorium contains the TAS assembler, TED editor and TDB debugger for TEC-OS.
These links open the existing manuals in the Thorium repository.

| Tool | Existing material |
| --- | --- |
| TAS | [Source language](https://github.com/jhlagado/thorium/blob/main/docs/language.md), [reading the assembler](https://github.com/jhlagado/thorium/blob/main/docs/readtas.md) and [debug-file format](https://github.com/jhlagado/thorium/blob/main/docs/format.md) |
| TED | [Editor and build workflow](https://github.com/jhlagado/thorium#ted) and [reading the editor](https://github.com/jhlagado/thorium/blob/main/docs/readted.md) |
| TDB | [Commands](https://github.com/jhlagado/thorium#tdb), [debugger implementation](https://github.com/jhlagado/thorium/blob/main/docs/tdb.md) and [reading the debugger](https://github.com/jhlagado/thorium/blob/main/docs/readtdb.md) |

Books on these tools can use separate navigation and chapter groups in this
library. The [TEC-OS book](../tec-os/index.md) includes the current editing,
assembly and service interfaces.
